# CampusSkill

Платформа обмена навыками и воркшопов для студентов: студенты-менторы проводят мастер-классы, участники записываются, получают напоминания, оставляют отзывы и копят прогресс по навыкам. Администратор модерирует воркшопы и пользователей.

Учебный проект по дисциплине «Проектный практикум», кейс №12, роль «Разработчик».
Автор — Дурницин Семён Дмитриевич, РИ-340938.

| Часть | Технологии |
|---|---|

| Инфраструктура | Docker Compose (PostgreSQL) |

## Быстрый старт

```bash
# 1. база данных
docker compose up -d

# 2. бэкенд — http://localhost:3000/api, Swagger — http://localhost:3000/api/docs
cd backend
npm install
cp .env.example .env
npx prisma migrate deploy
npx prisma generate
npx prisma db seed
npm run start:dev

# 3. фронтенд — http://localhost:5173 (в новом терминале)
cd frontend
npm install
npm run dev
```

Подробности — в [backend/README.md](backend/README.md) и [frontend/README.md](frontend/README.md).

## Роли и возможности

- **Участник** — каталог с поиском и 9 фильтрами, запись с автоподтверждением или в лист ожидания, отмена, личный кабинет (предстоящие и прошедшие записи, уведомления, прогресс, настройки), отзыв с двумя оценками после посещения.
- **Ментор** — всё, что у участника, плюс создание и редактирование воркшопов, отправка на модерацию, отмена, список участников с отметкой посещения, ответы на отзывы, профиль ментора.
- **Администратор** — очередь модерации (публикация, отклонение с причиной), снятие воркшопа с публикации, статистика платформы, поиск пользователей, блокировка и смена роли.

## Ключевой сценарий

Каталог с фильтрами → карточка воркшопа → запись → подтверждение → личный кабинет с предстоящим воркшопом → напоминание → отметка посещения ментором → отзыв.
